 📩 Customer Support Ticket System

A simple yet functional customer support ticket system built using HTML, CSS, and JavaScript. This project simulates a real-world helpdesk where users can submit complaints and track their ticket status.



🚀 Live Features

- Submit support tickets with name, email, and message
- Auto-generated ticket ID (e.g. TCK-1234)
- View all submitted tickets in a dashboard
- Update ticket status:
  - Pending
  - In Progress
  - Resolved
- Delete tickets when resolved
- Data saved in browser using localStorage (no backend required)

---

🛠️ Built With

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Browser LocalStorage

This project was built to practice:
